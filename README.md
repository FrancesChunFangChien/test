# 古典 Android TV 遙控器

一個古典風格（桃花心木 + 黃銅 + 象牙按鍵）的網頁遙控器，可以透過家裡的 Wi-Fi 真的控制 Android TV / Google TV。

## 為什麼需要「橋接程式」？

Android TV 的遙控協定（Android TV Remote protocol v2，和 Google TV 手機 App 相同）走的是 TCP + TLS 連線（埠號 6466／6467）。
一般網頁基於瀏覽器安全限制，**不能直接開 TCP 連線**，所以單純一個 HTML 檔沒辦法直接控制電視。

因此這個專案分成兩部分：

| 檔案 | 作用 |
|---|---|
| `android-tv-remote.html` | 遙控器網頁（介面） |
| `tv_bridge.py` | 橋接程式：在家裡一台電腦上執行，負責跟電視配對與送出按鍵，同時提供網頁 |

```
手機瀏覽器 ──HTTP──▶ 電腦上的 tv_bridge.py ──TLS (6466/6467)──▶ Android TV
```

## 需要什麼

- 一台和電視連在**同一個 Wi-Fi／區域網路**的電腦（Windows、macOS、Linux 或樹莓派 Raspberry Pi 都可以），使用遙控器時要保持開機
- Python 3.10 以上
- 電視是 Android TV 或 Google TV（需要內建「Android TV Remote Service」；Amazon Fire TV 不支援）

## 安裝與啟動

```bash
pip install -r requirements.txt
```

```bash
python tv_bridge.py
```

啟動後畫面會顯示一個網址，例如 `http://192.168.1.20:8765`，用手機或電腦瀏覽器開啟它。

## 第一次配對

1. 在電視的「設定 → 網路與網際網路」（各品牌位置略有不同）查到電視的 IP 位址
2. 在網頁輸入 IP，按「開始配對」
3. 電視上會出現 6 碼配對碼，輸入到網頁後按「確認配對」
4. 完成！之後重新啟動橋接程式會自動連線，不用再配對

配對產生的憑證存在 `atv_cert.pem`、`atv_key.pem`、`atv_config.json`（已加入 `.gitignore`，請勿上傳或分享）。

## 小技巧

- 方向鍵、音量、頻道可以**按住連續送出**
- 下方兩顆金色捷徑鍵可在「自訂捷徑鍵」改成其他 App（填網址或套件名稱 package name）
- 把網址加到手機主畫面（加入主畫面 Add to Home Screen），用起來就像一個 App
- 電腦上也能用鍵盤操作，按鍵對照表在網頁的「鍵盤快捷鍵」裡

## 常見問題

- **連不到電視**：確認 IP 正確、電視已開機、電腦和電視在同一個網路（有些路由器的「訪客網路」會隔離裝置）
- **電視待機後無法用電源鍵開機**：要看電視是否支援網路待機喚醒，請在電視設定中開啟類似「網路待機」「透過 Wi-Fi 開啟」的選項（名稱依品牌而異）
- **部分按鍵沒反應**：例如「節目表」「頻道」「語音助理」等，是否有作用取決於電視型號與目前的 App
- **安全性**：橋接程式沒有密碼，同一個 Wi-Fi 內的人都能打開網頁控制電視，請只在家用網路使用
